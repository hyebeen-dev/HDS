## 배경

사용자가 Product Detail의 결제/적립 정보 UI(카드할인, 적립, 혜택, 배송 등 라벨+내용 행)를 설계 중이며, "현재 규칙에 맞춰 컴포넌트를 생성"해달라고 요청. PRD 상 결제(체크아웃) 화면 자체는 제외 범위지만, 이 UI는 **Product Detail 안에서 조건부 가격·혜택을 보여주는 정보 행**이라 E-4("쿠폰·적립 등 조건부 가격이 있는 상품 — 조건부 금액의 표기 방식과 강조 단계") 요구사항에 해당해 범위 내로 판단했다.

## 레퍼런스 분석 및 범위 결정

두 레퍼런스(쿠팡 카드할인 안내, 네이버 적립/혜택/배송 패널)에서 공통 구조를 추출: **좌측 라벨 + 우측 내용**, 내용은 3가지 패턴(단순 텍스트 / 펼침 가능 / 링크 포함)으로 수렴한다. 네이버의 보라색 그라데이션 CTA 박스는 우리 Foundation 컬러 시스템과 무관한 브랜드 색이라 가져오지 않고, 구조 패턴만 참고했다.

## 실행 내용

`Info Row` COMPONENT_SET 신설, `Type` 속성(`Text` / `Expandable` / `Link`):

- 공통 구조: 라벨(고정폭 64px, Noto Sans KR Bold 13px, `Text/Primary`) + 내용(FILL, Noto Sans KR Regular 13px, `Text/Description`)
- **Type=Text**: 라벨+내용만 (예: "배송 · 무료배송 · 내일(수) 도착 보장")
- **Type=Expandable**: 내용 뒤에 펼침 화살표 — **기존 `Icon/Chevron Right`를 -90도 회전**해 재사용, 새 아이콘 제작 없음 (예: "적립 · 최대 444원 쿠팡캐시 적립 ⌄")
- **Type=Link**: 내용 아래 링크 버튼 — **기존 `Button/Text/Large/Default` 컴포넌트를 그대로 인스턴스로 재사용** (예: "카드할인 · 카드사 제휴 할인 결제 시 20,640원" + 링크 버튼)

## 실행 중 제약

Link variant의 버튼 라벨을 "자세히보기"로 바꾸려 했으나, 해당 텍스트가 Pretendard로 돼 있어 이 실행 환경에서 타이핑 불가 — 기존 "바로구매" 텍스트가 그대로 남아있다. 사용자가 직접 교체 필요.
