# HDS 디자인 시스템

AI Agent와 협업해 모바일 커머스 디자인 시스템을 구축하고, 그 시스템만으로 실제 화면을 만들 수 있는지 검증한 프로젝트의 문서입니다.

## 프로젝트 개요

쿠팡 앱에서 발견한 문제를 출발점으로 삼았습니다. 높은 정보 밀도, 가격 정보의 전달 방식, 리뷰 신뢰도 판단의 어려움이 그 문제입니다. 쿠팡의 디자인을 그대로 옮기지 않고, 문제를 해결하는 데 필요한 원칙과 컴포넌트를 직접 정의했습니다.

| 담당 | 역할 |
|---|---|
| 디자이너 | Foundation·Component 설계, Figma 작업, 디자인 의사결정, AI 결과물 검토 |
| AI Agent | Figma MCP를 통한 실측값 정리, 컴포넌트 수정, 문서 작성, 화면 제작 |

AI가 제안한 구조와 값은 디자이너가 검토한 뒤 확정한 것만 문서에 반영했습니다.

## 주요 결과

| 영역 | 결과 |
|---|---|
| Foundation | Semantic 색상 토큰 31개, 텍스트 스타일 29개, Spacing 16단계, Radius 5단계 |
| 변수 바인딩 | 컴포넌트 라이브러리의 padding·gap 1,380곳, radius 1,346곳 |
| Component | 체크리스트 15개 중 14개 완료, 추가 컴포넌트 3개 |
| 화면 검증 | 커머스 6개, 비커머스 5개 화면을 신규 컴포넌트 없이 제작 |

화면 검증은 AI Agent가 design.md만 근거로 화면을 만들고, 디자이너가 결과를 검토하는 방식으로 진행했습니다. 기존 컴포넌트를 재사용한 주문 내역 화면은 제작에 2분 42초가 걸렸습니다.

Foundation과 화면 구성 규칙은 비커머스 도메인에서도 그대로 적용됐습니다. 반면 컴포넌트는 대부분 커머스에 맞춰져 있어, 비커머스 화면에서는 차트, 콘텐츠 카드, 시간 그리드 같은 공백이 확인됐습니다. 이 공백은 status.md의 남은 과제에서 관리합니다.
